WEBSITE PROJECT README
======================

This package contains three simple website projects:
1. ShopEasy E-Commerce Store
2. ElectroMart Electronics Store
3. Grand Palace Hotel Website

--------------------------------------------------
1. ShopEasy E-Commerce Store
--------------------------------------------------
File: ecommers store.html

Purpose:
A basic e-commerce webpage for displaying products in an online store.

Main features:
- Store navigation and promotional content
- Product cards with names, prices, and discounts
- Shopping-related buttons and interface elements
- Styling built with HTML and CSS
- Basic JavaScript interactions where included in the source

How to run:
1. Keep the HTML file on your computer.
2. Double-click it, or right-click and open it with a web browser.
3. No server or installation is normally required for this standalone page.

--------------------------------------------------
2. ElectroMart Electronics Store
--------------------------------------------------
File: electronics store.html

Purpose:
An electronics catalog for browsing products such as laptops, smartphones,
accessories, and smart devices.

Main features:
- Electronics product listings
- Product details and pricing information
- Category/navigation elements
- Product presentation and responsive styling
- Basic JavaScript interactions where included in the source

How to run:
1. Keep the HTML file on your computer.
2. Double-click it, or right-click and open it with a web browser.
3. No server or installation is normally required for this standalone page.

--------------------------------------------------
3. Grand Palace Hotel Website
--------------------------------------------------
File: hotel.html

Purpose:
A hotel website that presents the property and its hospitality services.

Main features:
- Hotel-themed page layout
- Sections presenting the hotel and its services
- Navigation and visual styling
- Basic JavaScript interactions where included in the source

How to run:
1. Keep the HTML file on your computer.
2. Double-click it, or right-click and open it with a web browser.
3. No server or installation is normally required for this standalone page.

--------------------------------------------------
General Notes
--------------------------------------------------
- The original HTML files contain the source for each individual webpage.
- HTML defines the page structure, CSS handles appearance, and JavaScript
  provides any interactive behavior included in the original files.
- If a page uses online images, fonts, or other external resources, an internet
  connection may be needed for those resources to load.
- The combined code file contains all three source files, separated by clear
  headings. Save each section back to its own .html file if you want to run
  the pages separately.
- The PDF contains illustrative preview images for the three webpages. They
  are previews, not direct screenshots captured from a live browser session.
